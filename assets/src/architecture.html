Muse
How it is described to work

Its own computer, and hourly notes on you

You

App (iOS/Android), WhatsApp, or muse.ai. You give goals, approve actions, and can take over the same machine.

→

Muse Secure VM

An isolated Linux box per user, with a full browser. Other users' agents cannot reach it.

Muse agent

Muse Spark 1.3. Plans, browses, fills forms, checks out, keeps working after you close the app.

Sentinel

System-level isolation. Nothing the agent does reaches the internet unless Sentinel allows it.

→

The web & your apps

Email, shopping, travel, Slack, Shopify, Stripe, QuickBooks — 15+ connectors. Payments via Link's one-time-use card.

What it records (TIME, 2026-10-06)

An hourly dossier on you and the people you mention — how you met, shared interests, disputes, “tensions and alliances”. Non-users get mapped through other people's agents. Nightly analysis; cross-VM “shared lessons”. Asking it to forget does not guarantee the original message disappears.

Where the human stops it

Approval gates before sending, paying, or connecting a new app; per-connection permission levels; instant disconnect; audit trail; VM file export. A Confidential VM (whole-VM encryption, user-held key) is announced, not shipped.
